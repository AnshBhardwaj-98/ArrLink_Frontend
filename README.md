# ArrLink Website

A modern React website built with Vite, TypeScript, and shadcn-ui.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm or bun

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Build

```sh
npm run build
```

### Preview Production Build

```sh
npm run preview
```

## Available Scripts

- `dev` - Start development server
- `build` - Build for production
- `build:dev` - Build in development mode
- `lint` - Run ESLint
- `preview` - Preview production build
- `test` - Run tests
- `test:watch` - Run tests in watch mode

## Website structure and SEO

The redesign keeps the existing React/Vite stack, project data, blog pipeline,
EmailJS integration and Vercel deployment. The main navigation is Services, Technology,
Our work, About us and Insights. All six portfolio projects remain in
`src/content/projects.ts`; all six projects are visible on the homepage.

Industry landing pages and the old hero frame sequence were removed. Permanent
Vercel redirects send `/industries` and `/industries/:slug` to `/services`;
React Router handles those paths in local development as well.

`src/seo/routes.ts` owns titles, descriptions and canonical routes. `npm run build`
prerenders each page and generates `dist/sitemap.xml` and the blog RSS feed.
Production URLs use `https://www.arrlink.com`; change `SITE_URL`, the static tags
in `index.html`, and `public/robots.txt` together if the domain changes. Keep
explicit `lastmod` dates on content whose update date is known.

The form requires the EmailJS variables listed in `.env.example` in the deployment
environment. Without them, visitors receive a visible email fallback. Automated
tests mock EmailJS; real email delivery must be checked with production credentials.

### Visual assets

- `public/images/connected-ideas.webp`: original AI-generated hero, 1000 × 1000.
- `public/images/connected-ideas-small.webp`: responsive 600 × 600 version.
- `public/images/social-preview.png`: 1200 × 630 social sharing card.

The built-in image generation tool produced the original artwork with this prompt:

> Use case: stylized-concept. Asset type: software development studio website hero illustration. Create an exquisite editorial 3D still life of three interlocking architectural ribbon loops, one burnt orange ceramic, one ivory matte, one charcoal brushed metal, suggesting a connected arrow and modular software building blocks. Warm cream seamless studio background #f4f1e9, soft natural side lighting, realistic contact shadows, fine tactile surfaces. Sculptural, sophisticated, minimal, large centered object filling a square composition, slightly elevated three-quarter camera. No text, no logos, no screens, no watermark. The website uses cream, charcoal and burnt orange.

Project illustrations are code-native graphics, explicitly labeled as illustrations,
not product screenshots. The existing project descriptions and links are preserved.


### UI conventions and asset layout

UI conventions are adapted from the supplied `UI-GUIDELINES.md`: semantic CSS
color tokens, compact corner radii, accessible form labels and errors, and a
consistent local system font stack. The existing React/Vite architecture remains.
No external font downloads are required.

- `public/brand-mark.svg`: shared navbar/footer mark and SVG favicon.
- `public/favicon.ico`: small-size browser fallback.
- `public/apple-touch-icon.png`: touch-device icon.
- `public/images/brand-mark.png`: raster logo for organization structured data.
- `public/images/connected-ideas*.webp`: responsive hero/about artwork.
- `public/images/social-preview.png`: sharing preview.

The unused root hero video, old logo, empty frame directory, and `stitch/`
prototype were removed. Source lives in `src/`, build scripts in `scripts/`, and
supporting documents in `docs/`. `dist/` and `dist-server/` are generated by the
build and should not be edited or committed.

The homepage client strip names existing clients and identifies Imagine.bo as
Synergylabs’ project. ConectDesk is explicitly labeled as an ArrLink product.
Technology and engagement sections are shared by the homepage and Services page.
Project inquiry links preselect the engagement type; the contact form includes
that choice and optional time-zone preferences in EmailJS’s existing `message`
parameter, so the email template does not need new fields.
